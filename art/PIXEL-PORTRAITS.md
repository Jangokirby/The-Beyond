# Pixel portraits: how to make them

`asset-list-pixel.csv` has one row per person (the 132 agent portraits and the named characters of every job).
The painted portraits turn muddy when shrunk, so these are drawn as pixel art from the start.

* **Style:** a bust, face large, strong dark outline, 16 colours or fewer, flat shading, crisp square pixels, no blur or gradients.
* **Background:** one flat colour, nothing else. The game cuts the person out and stands them in the scene.
* **Size:** any size, as long as every pixel block is the same size (for example a 64x64 grid drawn at 512x512). The game reduces it to 64x64.
* **Names:** keep the file names. They are the same as the painted ones, in the folder `portraits-pixel/`.
* **Black and white:** make them in colour. The game turns them to grey or to one colour per era.
