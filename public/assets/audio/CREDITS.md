# Sound effects and ambience (assets/audio/sfx)

Every sound effect and ambience bed is a recording. All of them come from **BigSoundBank.com by Joseph SARDIN**, released
under **CC0 1.0** (free for any use, including commercial; no credit required, but credited here and on the Credits screen as
the author asks: "Additional sounds: Joseph SARDIN - BigSoundBank.com"). Recordings were trimmed, levelled to one loudness,
and some were slowed down, reversed or given an echo to make them stranger. Ambience beds are seamless loops (the end
crossfades into the start). Any file can be replaced by another recording with the same name. If a file is missing, the
game makes a stand-in in code (js/synth.js).
